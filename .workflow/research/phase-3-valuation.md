## 1. Simply Wall St — the closest template for §4–§5 (per-industry model choice + 6 checks)

- SWS uses **both intrinsic and relative valuation**, folded into 6 checks that form the Valuation arm of the Snowflake (2 intrinsic + 3 relative + 1 analyst-target): https://support.simplywall.st/hc/en-us/articles/4751563581071-Understanding-the-Valuation-section-in-the-company-report (fetched 2026-10-10).
- Intrinsic = DCF-family fair value; the two intrinsic checks are (a) price below fair value → 1 pass, (b) price ≥20% below fair value → 2nd pass: same URL (fetched 2026-10-10).
- **4 DCF variations chosen by industry/data availability** — this is the direct precedent for roadmap §4 "multiple models per industry": (1) 2-stage FCFE DCF for general companies; (2) Dividend Discount Model when 2-stage DCF unavailable / consistent dividend payers; (3) Excess Returns model for banks/insurers; (4) AFFO 2-stage DCF for REITs: same URL (fetched 2026-10-10). Open-source model doc confirms identical 4-way split: https://github.com/SimplyWallSt/Company-Analysis-Model/blob/master/MODEL.markdown (fetched 2026-10-10).
- 2-stage DCF mechanics: 10-yr levered-FCF forecast from analyst consensus where available, else extrapolation of last reported FCF at historical growth with decaying growth rate; terminal value via Gordon Growth using **5-yr average long-term government bond rate** as perpetual g; discount at cost of equity; divide by shares outstanding (worked MSFT example: FCF2033-based terminal value $3.66T, PV $1.83T, fair value $361.80 vs $312.79 price): https://support.simplywall.st/hc/en-us/articles/4751563581071-Understanding-the-Valuation-section-in-the-company-report (fetched 2026-10-10).
- DDM mechanics: Value = Expected DPS / (discount rate − perpetual growth); example BSE:530365 ₹1 / (17.80% − 6.76%) = ₹9.05: same URL (fetched 2026-10-10).
- Excess Returns mechanics (banks): Excess Return = (Stable ROE − Cost of Equity) × Stable Book Value; Terminal Value of Excess = Excess / (CoE − g); Fair Value/share = Stable BV/share + Terminal Value of Excess (worked BAC example: (9.8% − 7.61%) × $35.38 = $0.78 → $14.26 terminal → $49.64 fair value): same URL (fetched 2026-10-10).
- AFFO DCF (REITs): identical to 2-stage DCF but discounts AFFO (FFO = earnings + D&A − property-sale gains; AFFO further − maintenance capex + rent uplifts); falls back AFFO → FFO → FCF in that order (worked AMT example → $322.93): same URL (fetched 2026-10-10).
- Relative leg: preferred multiple auto-selected P/E (profitable, P/E<150) → P/S (growth/early-stage) → P/B (banks/financials where asset base drives income), with explicit decision flowchart: same URL (fetched 2026-10-10). Three relative checks: multiple vs editable peers, vs industry, vs proprietary "Fair Ratio" (model of what market pays for growth at given risk, fitted per market+industry on thousands of datapoints): same URL (fetched 2026-10-10).
- Peer comparison shows peer-average line + per-peer forward multiple, estimated growth, market cap, with "Edit Peers" control — REUSED from Phase-2 file, re-verified live (SNOW PS 21.7x vs peer avg 21x; TMGH PE 12.4x vs peer avg 10.4x, fair PE 10.5x): https://simplywall.st/stocks/us/software/nyse-snow/snowflake/valuation and https://simplywall.st/stocks/eg/real-estate-management-and-development/case-tmgh/talaat-moustafa-group-holding-shares/valuation (both fetched 2026-10-10).
- **EGX coverage is live:** SWS publishes CASE:COMI and CASE:TMGH valuation pages; TMGH snapshot: price EGP 92.8 vs future-cash-flow value EGP 150.54 (passes both intrinsic checks, score 3/6); data provenance footer cites 10-yr company financials (SEC 10-K/10-Q for US), +3-yr analyst estimates, 30-yr market prices: https://simplywall.st/stocks/eg/real-estate-management-and-development/case-tmgh/talaat-moustafa-group-holding-shares/valuation (fetched 2026-10-10). COMI page exists but depth not fully rendered in this pass: https://simplywall.st/stocks/eg/banks/case-comi/commercial-international-bank-egypt-cibe-shares/valuation (fetched 2026-10-10).
- **Adjustable inputs: essentially none on the report itself.** Peer list and displayed ratio are editable but "this will not change the result of the analysis" (still scored on defaults): https://support.simplywall.st/hc/en-us/articles/4751563581071-Understanding-the-Valuation-section-in-the-company-report (fetched 2026-10-10). Independent review corroborates fair-value model is a non-adjustable black box (REUSED, 2026-10-10). Adjustability lives in the separate Community Narratives product (user sets revenue, margin, future P/E, price-in-year → own fair value, e.g. PayPal narrative "Exit 12x → ~$100 in FY2030, discount 4.5yrs at 10% → $65"): https://simplywall.st/community/narratives/us/diversified-financials/nyse-htaq.u (fetched 2026-10-10).
- **Uncertainty display: threshold-based, not ranges.** 20% discount = "significantly below"; analyst check requires BOTH ≥20% discount AND dispersion (high−low) within 15% of consensus = "Good" confidence, else "Low": https://support.simplywall.st/hc/en-us/articles/4751563581071-Understanding-the-Valuation-section-in-the-company-report (fetched 2026-10-10). TMGH live example shows the failure state: target +52.9% above price BUT dispersion 17.87% → "analysts are not within a statistically confident range": https://simplywall.st/stocks/eg/real-estate-management-and-development/case-tmgh/talaat-moustafa-group-holding-shares/valuation (fetched 2026-10-10). No sensitivity grid, no bull/base/bear on the report: `no data` — none observed on any SWS valuation/help page fetched 2026-10-10.

## 2. Morningstar — the uncertainty-display gold standard (§5 confidence model)

- Core: proprietary 3-stage DCF of free cash flow to the firm (FCFF = EBI + net new investment), discounted at WACC; **banks/financials use free cash flow to equity discounted at cost of equity**; multiples used only as cross-checks: https://www.morningstar.com/content/dam/marketing/shared/research/methodology/705988Morningstar_Equity_Research_Methodology.pdf and https://s205.q4cdn.com/437373358/files/doc_downloads/2025/07/Morningstar-Equity-Research-Methodology-2023-06-14.pdf (both fetched 2026-10-10). Plain-English definition: fair value = all future free cash flows discounted at a risk-commensurate rate; highly sensitive to projections: https://www.morningstar.com/investing-terms/fair-value-estimate (fetched 2026-10-10).
- Star rating = 4 inputs (moat + fair value + Uncertainty Rating + market price); DCF preferred explicitly for cyclicals, high-growth, finite-life (mines), negative-earnings companies: https://www.morningstar.com/content/dam/marketing/shared/research/methodology/705988Morningstar_Equity_Research_Methodology.pdf (fetched 2026-10-10).
- **Uncertainty Rating scale: Low / Medium / High / Very High / Extreme**, defined as analysts' ability to bound fair value (interquartile 25th–75th percentile range): https://www.morningstar.com/investing-terms/uncertainty-rating and https://www.morningstar.com.au/s/documents/MCA_GlobalEquityReportDisc.pdf (both fetched 2026-10-10).
- **Margin-of-safety thresholds (buy/sell) widen with uncertainty** — Consider Buying at 95/90/85/80/50% of fair value and Consider Selling at 105/110/115/125/200% across Low→Extreme: https://www.morningstar.com/stocks/how-measure-stocks-uncertainty (fetched 2026-10-10). 5-star/1-star calibration: 20%/25% (Low), 30%/35% (Medium), 50%/75% (Very High), 75%/300% (Extreme): https://advisor.morningstar.com/Enterprise/VTC/URFAQ.pdf and https://www.morningstar.com.au/s/documents/MCA_GlobalEquityReportDisc.pdf (both fetched 2026-10-10).
- Uncertainty drivers analysts weigh: operating leverage (fixed costs), financial leverage (debt), contingent events (lawsuits), profitability/runway — e.g. Coca-Cola/J&J/Home Depot = Low; Alphabet/Microsoft/Oracle = Medium (tech evolution); ExxonMobil/Netflix = High; Tesla = Very High; Hawaiian Electric (wildfire suits) = Extreme: https://www.morningstar.com/stocks/how-measure-stocks-uncertainty (fetched 2026-10-10).
- **Adjustable inputs: none for retail users** — analyst-owned DCF templates with custom industry/company assumptions; quantitative variant refits nightly via random forest: https://morningstardirect.morningstar.com/clientcomm/QERFinal_V2.pdf (fetched 2026-10-10). Bull/base/bear probability-weighting is mentioned as an input option ("base-case forecasts … or explicitly probability-weighting scenario-based estimates"): same URL (fetched 2026-10-10), but no public scenario UI: `no data`.
- **Design steer for §5:** copy the *widening margin-of-safety ladder* (our confidence score → required discount before "undervalued" verdict), but feed it from our data-quality score instead of analyst judgment — no competitor ties uncertainty display to machine-readable data provenance.

## 3. Yahoo Finance — what "fair value" means there (thin; do not copy as valuation engine)

- Yahoo's own "fair value" help article = **Peter Lynch formula**: Fair Value = EPS × EPS Growth Rate; P/E = Growth Rate at fair value; growth capped 0–40%; price data daily, fundamentals weekly; negative EPS → N/A: https://help.yahoo.com/kb/SLN29279.html (fetched 2026-10-10).
- Rate-of-Return bands: P/E ÷ growth <1.0 undervalued; 1.0–2.0 near fair value; >2.0 overvalued; dotted fair-value line = in-progress fiscal year / stale data: same URL (fetched 2026-10-10).

## 7. Which inputs EGX filings actually support (ties to financial_statements MISSING reality)

- Listing Rules require annual + periodic statements, notes, audit reports pre-trading, published via EGX; listing applicants file 2 prior fiscal years under Egyptian Accounting Standards (EAS), FRA-registered auditor; foreign listers may use IFRS/American standards with Arabic translation: https://www.egx.com.eg/getdoc/f37356af-a80b-473c-ae8c-be023258dcfe/Listing-Rules_en-16-03-2022.aspx (fetched 2026-10-10). Continuing obligations include quarterly disclosure reports (shareholder/board/treasury structure on FRA forms): https://resourcehub.bakermckenzie.com/en/resources/cross-border-listings-guide/europe-middle-east--africa/egyptian-exchange/topics/continuing-obligationsperiodic-reporting (fetched 2026-10-10).
- EAS ≠ IFRS: EAS built from IFRS-base but not identical/comprehensive (2015 base, 2019 IFRS 9/15/16 alignment, 2023 IFRS-17-like insurance); key deltas — employee profit-sharing = equity distribution not expense; PPE/intangibles/investment-property revaluation disallowed until Jan 2023; no single-statement comprehensive-income option; no equity method in separate statements; IFRS fallback for unaddressed items: https://www.ifrs.org/content/dam/ifrs/publications/jurisdictions/pdf-profiles/egypt-ifrs-profile.pdf (fetched 2026-10-10).
- **Statement availability (primary evidence):** EGX-company filings contain the full 5-statement set — financial position, income, comprehensive income, changes in equity, cash flows + notes (SIDPEC H1-2024 limited-review pack shows all five + ECL/impairment notes): https://www.egx.com.eg/downloads/Bulletins/310486_2.pdf (fetched 2026-10-10). Banks add CBE-instruction overlays (EAS + CBE 26-Feb-2019 instructions; credit-loss, provision, FVOCI lines) with full cash-flow reconciliation (Banque du Caire 2025, Crédit Agricole 2024/Q1-2025 packs): https://www.bdc.com.eg/bdcwebsite/dam/jcr%3Afee0f6b2-c84f-4df0-97cd-edea7784e266/BDC-Consolidation-Dec-25-En.pdf and https://www.ca-egypt.com/app/uploads/2025/02/Consolidated_Financial_Statements_31_December_2024_English.pdf (both fetched 2026-10-10). EFG Holding Q1-2026 separate statements show EPS, dividends income, operating/investing/financing cash flows: https://efgholding.com/uploads/EFG_Holding_Standalone_Financial_Statements_1_Q2026_8c8e975ea8.pdf (fetched 2026-10-10).
- **What this means for §4 model inputs:** income-statement + balance-sheet + cash-flow + dividends + share-count inputs are **supported** (all five statements exist per filing). Analyst-consensus growth inputs are **weak** for EGX (4–10 analysts on large caps like COMI/ETEL vs 40–88 on US mega-caps per SWS disclosures: https://simplywall.st/stocks/eg/real-estate-management-and-development/case-tmgh/talaat-moustafa-group-holding-shares/valuation vs https://simplywall.st/stocks/at/tech/vie-aapl/apple-shares/valuation, both fetched 2026-10-10) — so EGX DCFs must fall back to historical-extrapolation paths the way SWS already does when estimates are missing. Government-bond-rate terminal-g anchor for EGP: `no data` — SWS uses "5-yr average long-term government bond rate" generically; no EGP-specific rate retrieved in this pass.
- Filing **machine-readability**: EGX disclosures are PDFs (third-party archive counts 5,419 PDFs / 244 companies, noting EGX removes files from its own site): https://foudalens.com/en/disclosures (fetched 2026-10-10). Structured XBRL/API: `no data` — none found 2026-10-10. This is the binding constraint behind §5's confidence-fed-by-data-quality requirement.

## 8. Standing req 3 → §4 mapping (industry profiles feed model choice)

- No competitor publishes a per-industry valuation-method dictionary for EGX: `no data` (carried over from Phase-2 A5; re-confirmed 2026-10-10 — SWS model-selection is per-company-behind-the-scenes, Koyfin templates are user-built, Morningstar templates are analyst-owned, InvestingPro applies all 15+ models uniformly).
- Concretely supported mapping from this pass (each row cited above):
  - **Banks / financials → Excess Returns (SWS) / FCFE-at-CoE (Morningstar) + P/B preferred multiple; DDM as fallback.** Academic grounding: Damodaran FCFE-vs-DDM decision rule (dividends within 80–110% of FCFE → DDM acceptable; banks/FCFE-hard-to-estimate → DDM) and excess-return framing: https://pages.stern.nyu.edu/~adamodar/pdfiles/ovhds/dam2ed/dcfveg.pdf (fetched 2026-10-10).
  - **General non-financials → 2-stage FCFE DCF + P/E-or-P/S relative + Fair-Ratio cross-check + analyst-target check** (SWS default path).
  - **REITs / real-estate income → AFFO-DCF; Egyptian developers (TMGH) → SOTP (project DCFs + EBITDA multiples on recurring assets)** — SWS AFFO method + TMGH SOTP corroboration (§1, §5).
  - **Dividend payers → DDM fallback** when FCF forecasts unavailable.
- §4 exit-criteria implication: `industry_valuation_profile` = (industry_id, primary_model, fallback_model, preferred_multiple, methodology_version); every fair-value response carries profile id + version + per-model values + weights + N-with-data — the weighted-fair-value + confidence design has **no direct competitor precedent** (InvestingPro weights models but publishes no weights/versions; SWS picks one model opaquely).
